Agent stage — what the robots do while they work

Each tool gets its own activity. Sub-agents appear next to the lead robot, each with its own job.

3 · How it behaves

Sub-agent startsA new robot pops out of a smoke puff next to the lead; a page flies along the dashed line (the hand-off). Each robot's activityFollows its current tool: Read → book, Edit/Write → typing at a desk, Bash → hammer, Grep/Glob → magnifier, Web → globe, no tool → thinking, waiting for approval → hand up with “!”. Sub-agent finishesIt waves with a ✓, walks the page back to the lead along the line, and poofs away. Name + taskEach robot has a name tag (agent type) and its task underneath; hover = full task + current command. Colours / outfitsLead = the chat's robot (its colour + outfit). Sub-agents = smaller, each type with its own colour (Explore teal, Plan purple, general orange…). Lots of agentsUp to 4 shown; more → “+3” chip that opens the full list.
