Shelter UI

Components and screen structure for the HUD's Shelter style: an underground base with riveted steel panels, amber accents and teal readouts. Each component lists the app class it maps to, so this page can be checked against ui/styles/theme-shelter.css.

01 Colour

Steel greys for everything structural. Amber marks action and needs-you. Teal marks live data and working. Red is only for danger and errors.

10 Chat box layout (redesign)

Today the chat keeps the old messenger layout: a column of two big profile pictures on the left, a separate "working" box, and the input below it. At a normal HUD width that column eats ~90px, so the input toolbar runs out of room. The redesign gives the full width to the conversation and merges the status into the input.

Proposed

What moves where

  1. Comms strip (top, 40px): small porthole with the robot, name, status badge, and folder · branch as one readout line. Replaces the big agent picture and the floating git box.
  2. Context gauge as a 3px line under the strip, not a separate row.
  3. Transcript uses the full width. Claude's cards on the left, yours on the right; no picture column.
  4. Status lip: the working line becomes the top edge of the input console. The runner robot sits on it. When idle the lip shrinks to a thin amber line, so nothing jumps.
  5. Console toolbar: tools on the left (📎 / ✂ ⚡), then model and usage, then Send. Copy and the rest move into a ⋯ menu.
  6. Your picture moves into the strip's right end (small), where it also opens My Avatar.

Gained: ~90px for messages and the toolbar; one box fewer; nothing overlaps.

11 Rules

  • One amber plate per screen. Everything else is a steel key cap or a quiet button.
  • Amber means "you". Needs input, selected, your next action. Teal means "it's alive": working, live values, links.
  • Sunken = data, raised = control. Readouts, fields and the transcript are inset black; buttons are raised steel.
  • No hazard stripes, no edge stripes. Steel borders only; colour comes from text, badges and glows.
  • Readable first. Messages stay Segoe UI 12.5 on a dark card with ≥ 7:1 contrast; decoration (rivets, scanlines) stays faint.
  • Original look. Our robots, rooms and furniture. No characters, logos, door shapes or colour schemes from existing games.
